# Truncated 75-run grid (not cited)

This folder is a partial batch: 4 of 75 planned runs
(5 scenarios × 5 conditions × seeds 0–2). Sequential throughput was about
4 minutes per run (~5 hours for the full grid), so the batch was stopped and
replaced by the complete one-seed grid in `../final_grid25/`.

The four records here are exploratory and are **not** used in the report.
